====================================================================
Gemini 品質改善プロンプト（段階的アプローチ）
====================================================================

【状況】
低品質な画像が来た場合、以下の順番で改善依頼をしてください。


====================================================================
【ステップ1】まず現状を確認
====================================================================

受け取った画像の問題を特定：

□ ぼやけている（ドット絵じゃない）
□ サイズが違う
□ 色が違う
□ 透過背景になっていない
□ コマ数が違う
□ ディテールが粗い
□ シェーディングがない

→ 当てはまる問題に応じて、以下のプロンプトを使用


====================================================================
【ステップ2】ドット絵スタイルを要求
====================================================================

【問題】ぼやけた画像、リアルすぎる、AIイラストっぽい

【プロンプト】
```
これはドット絵（ピクセルアート）ではありません。

16ビット時代のクラシックゲーム（スーパーファミコン、ゲームボーイアドバンス）
のようなドット絵スタイルで作り直してください。

要件:
- すべてのピクセルがくっきり見える
- アンチエイリアシングなし
- ピクセル単位で手作業で配置されたような精密さ
- 32x48ピクセルのドット絵

参考ゲーム:
- クロノトリガー
- ファイナルファンタジー6
- ポケットモンスター（GBA版）
- スターデューバレー

キャラクター設定は同じ:
- 髪: #3d2817（黒茶色）
- 瞳: #ffb347（オレンジ黄色）
- 服: #8b6f47（茶色）

サイズ: 96x48px（32x48pxが3コマ横並び）
形式: PNG透過背景
```


====================================================================
【ステップ3】ディテールを追加
====================================================================

【問題】ドット絵だけど、シンプルすぎる、のっぺりしている

【プロンプト】
```
良いドット絵になりました。
さらにディテールを追加して、プロフェッショナルレベルにしてください。

追加してほしい要素:

1. シェーディング（陰影）
   - 髪: 3色（ベース、ハイライト、影）
   - 瞳: 輝きを表現（ハイライトを追加）
   - 服: 3色（ベース、明るい部分、暗い部分）
   - 肌: 2-3色（ベース、ハイライト、影）

2. アウトライン
   - キャラクターの輪郭を黒または濃い色で明確に
   - 顔のパーツ（目、口）も輪郭を強調

3. 細部の表現
   - 髪の流れや束感
   - 服のシワや質感
   - 剣のディテール
   - 足元の表現

参考: クロノトリガーの主人公クロノのスプライト
```


====================================================================
【ステップ4】色を修正
====================================================================

【問題】色が指定と違う

【プロンプト】
```
色を正確に修正してください。

正確なHEXコード:
- 髪のベース色: #3d2817
- 瞳のベース色: #ffb347
- 服のベース色: #8b6f47
- 肌のベース色: #ffcdb2

これらの色を正確に使用してください。
シェーディング（明暗）は、これらのベース色から明るく/暗くしたバリエーションを使ってください。
```


====================================================================
【ステップ5】サイズを修正
====================================================================

【問題】サイズが違う、拡大/縮小されている

【プロンプト】
```
サイズが正確ではありません。

正確なサイズ:
- 1コマ: 32ピクセル（横）× 48ピクセル（縦）
- 3コマ合計: 96ピクセル（横）× 48ピクセル（縦）

重要:
- リサイズしないでください
- 最初から96x48ピクセルで作成してください
- ピクセルパーフェクトな状態を維持してください
```


====================================================================
【ステップ6】アニメーションを改善
====================================================================

【問題】3コマの動きが不自然、ぎこちない

【プロンプト】
```
アニメーションを改善してください。

歩行サイクル:
- コマ1: 左足が前、右足が後ろ
- コマ2: 両足が揃っている（中間ポーズ）
- コマ3: 右足が前、左足が後ろ

要件:
- 滑らかな動き
- 体の上下動を表現（歩くときの自然な揺れ）
- 腕の振りを少し表現
- 3コマをループさせると自然な歩行に見える

参考: 16ビット時代のRPGの歩行アニメーション
```


====================================================================
【ステップ7】最終的なクオリティチェック
====================================================================

【すべて改善した後の最終確認プロンプト】

【プロンプト】
```
最終確認をお願いします。

以下の要件をすべて満たしているか確認してください:

✓ ドット絵スタイル（ピクセルパーフェクト）
✓ サイズ: 96x48px（32x48pxが3コマ）
✓ 髪: #3d2817（黒茶色、3色シェーディング）
✓ 瞳: #ffb347（オレンジ黄色、輝きあり）
✓ 服: #8b6f47（茶色、3色シェーディング）
✓ 透過背景
✓ くっきりした輪郭線
✓ 滑らかな歩行アニメーション
✓ プロフェッショナルレベルの品質

もし不足している点があれば、修正してください。
```

5. アウトラインを整える

====================================================================
【最終手段】画像編集ツールを使う
====================================================================

Geminiで満足な品質が得られない場合、以下のオプションも検討:

【オプション1】他のAIツールを試す
- DALL-E 3（ChatGPT Plus）
- Midjourney（Discord）
- Stable Diffusion（ローカル環境）

プロンプト: 「pixel art character sprite, 32x48, walking animation, 
             3 frames, retro game style, professional quality」

【オプション2】無料ドット絵ツール
- Aseprite（有料だが高品質）
- Piskel（無料オンライン）
- LibreSprite（Asepriteの無料版）

自分で作成するか、フリーランスのピクセルアーティストに依頼

【オプション3】フリー素材を使用
- OpenGameArt.org
- itch.io（ピクセルアートアセット）
- Kenney.nl（無料ゲームアセット）

既存の素材を改変して使用（ライセンス確認必須）


====================================================================
【参考】高品質ドット絵の特徴
====================================================================

プロフェッショナルなドット絵の条件:

✓ ピクセルパーフェクト
  → すべてのピクセルが意図的に配置されている

✓ 限定カラーパレット
  → 各パーツ3-4色程度

✓ くっきりした輪郭
  → 黒または濃い色のアウトライン

✓ 効果的なシェーディング
  → 光源を意識した陰影

✓ 読みやすさ
  → 小さいサイズでも何を表しているか明確

✓ 一貫性
  → すべてのコマで同じスタイル

✓ 滑らかなアニメーション
  → 自然な動きの流れ
