# ティウム村 マップ実装ガイド

## 📍 概要

ティウム村は『星の子』の始まりの村で、プレイヤーが冒険を始める場所です。
温かく平和な農村で、主人公の故郷として描かれます。

---

## 🗺️ マップ仕様

### サイズ
- **幅**: 40タイル (1280ピクセル)
- **高さ**: 30タイル (960ピクセル)
- **タイルサイズ**: 32×32ピクセル

### プレイヤースポーン地点
- **座標**: (20, 25) - 村の南側入口付近
- **ピクセル座標**: (640, 800)

---

## 🏘️ 村の配置

### 中央広場エリア
- **井戸**: (20, 15) - 村の中心
- **石畳**: 広場周辺 (17-23, 13-17)
- **花**: 装飾として配置

### 民家（6軒）
1. **北西の家**: (10, 8) - 3×3タイル
2. **北東の家**: (27, 8) - 3×3タイル
3. **西の家**: (8, 18) - 3×3タイル
4. **東の家**: (30, 18) - 3×3タイル
5. **南西の家**: (10, 23) - 3×3タイル
6. **村長の家**: (18, 26) - 5×4タイル（大きめ）

### 施設
- **雑貨屋**: (32, 14) - 4×3タイル（東側）
  - インタラクション: `shop`
  - アイテム購入可能

### 農業エリア
- **北側の畑**: 
  - 西側: (5, 3) - 8×4タイル
  - 東側: (28, 3) - 8×4タイル

### 装飾
- **木**: 6本配置（村の各所）
- **花**: 4箇所（広場周辺）
- **看板**: (20, 28) - 村の入口
  - インタラクション: `welcome_sign`
  - テキスト: 「ティウム村へようこそ」

### 外周
- **木の柵**: 村の周囲を囲む
- **入口**: 南側に開口部（18-22タイル）

## 🎮 使用方法

### 開発者向け

#### マップの初期化
```javascript
// map_tileset.jsが読み込まれていれば自動的に利用可能
const villageMapData = initializeTiumVillageMap();
const map = new Map(
    villageMapData.width,
    villageMapData.height,
    villageMapData.tileSize,
    villageMapData
);
```

#### デバッグモード
```javascript
// ブラウザのコンソールで実行
window.showGrid = true;    // グリッド線を表示
window.showDebug = true;   // オブジェクト名を表示
```

### プレイヤー向け
- ゲーム開始時に自動的にティウム村が読み込まれます
- WASDキーで村内を移動できます
- 建物や柵には衝突判定があり、通過できません
- 将来的に看板や雑貨屋とインタラクション可能になります
