## 実装した機能

### 1. プレイヤーステータス管理

#### レベル成長システム

```gdscript
# レベル1〜40のステータスを自動計算
HP:      100 → 900 (Lv.1 → Lv.40)
攻撃力:   15 → 132
防御力:    5 → 44
最大SP:   50 → 284
```

#### 星力段階システム

| 段階 | 名称 | 解放方法 | できること |
|---|---|---|---|
| 0 | 未解放 | 初期状態 | 星力使用不可 |
| 1 | 星力感知 | ストーリーイベント | SPゲージ表示 |
| 2 | 星力操作 | 修行イベント | 星灯陣のみ使用可能 |
| 3 | 魔法陣展開 | 修行イベント | 戦闘用魔法陣使用可能 |
| 4 | 星紋熟練 | 高度な修行 | 魔法陣威力+20% |

#### SP回復システム

- **戦闘外**: 5秒経過後、毎秒1SP自然回復
- **戦闘中**: 自然回復なし
- **回復薬**: 小(40SP)、中(100SP)、大(200SP)

### 3. ダメージ計算システム

#### 剣攻撃

```
ダメージ = max(1, floor((攻撃力 + 武器威力) × 補正 - 敵の防御力))
```

**特徴:**
- 主人公の攻撃力が影響
- 装備武器の威力を加算
- 会心判定あり（5%）

#### 魔法陣

```
ダメージ = max(1, floor(魔法威力 × 熟練度 × 属性 - 敵の防御力))

熟練度補正:
- 段階3: 1.0倍
- 段階4: 1.2倍

属性補正:
- 弱点: 2.0倍
- 通常: 1.0倍
- 耐性: 0.5倍
```

**特徴:**
- 主人公の攻撃力は影響しない
- 魔法陣固有の威力のみ
- 属性相性が非常に重要

#### ダメージ計算例

**例1: Lv.10、剣攻撃**
```
主人公攻撃力: 42
武器威力: 10
敵の防御力: 5

ダメージ = (42 + 10) - 5 = 47
```

**例2: Lv.25、火炎陣（段階4、弱点）**
```
魔法威力: 35
熟練度: 1.2倍
属性補正: 2.0倍（弱点）
敵の防御力: 12

ダメージ = floor(35 × 1.2 × 2.0 - 12)
         = floor(84 - 12)
         = 72
```

### 4. 戦闘システム

#### 戦闘の流れ

```
1. プレイヤーが攻撃ボタン押下
   ↓
2. 攻撃範囲内の敵を検索
   ↓
3. ダメージ計算
   ↓
4. 敵にダメージ適用
   ↓
5. クールダウン開始
   ↓
6. 戦闘状態に移行（5秒間）
```

#### 魔法陣発動の流れ

```
1. プレイヤーが魔法陣ボタン押下
   ↓
2. 発動条件チェック
   - 習得済み？
   - SP足りる？
   - クールダウン終了？
   - 星力段階OK？
   ↓
3. SP消費
   ↓
4. ダメージ計算（属性補正含む）
   ↓
5. 敵にダメージ適用
   ↓
6. クールダウン開始
```

## 技術的な注意事項

### データ読み込み

- JSONファイルは `res://data/` に配置
- エディタでインポートが必要（初回起動時に自動）

### シグナル接続

- `PlayerStats` のシグナルをUIが受け取る構造
- HUDは `set_player()` で初期化が必要

### 星力段階の管理

- 段階0〜4の5段階
- 段階1以降でSPゲージが表示される
- 段階3以降で戦闘用魔法陣が使用可能

### クールダウン管理

- 各魔法陣ごとに個別のクールダウン
- `_process(delta)` で毎フレーム更新

### SP自然回復

- 戦闘終了5秒後から毎秒1SP回復
- 攻撃やダメージを受けるとタイマーリセット

## デバッグ用関数

プレイヤーノードには以下のデバッグ関数があります：

```gdscript
# 星力解放
player.debug_unlock_star_power(3)  # 段階3を解放

# 魔法陣習得
player.debug_learn_magic_circle("magic_001")  # 光弾陣

# 経験値獲得
player.debug_gain_exp(50)  # 経験値+50

# レベル設定
player.debug_set_level(20)  # レベル20に設定
```

これらはGodotのデバッガコンソールから実行可能です。
