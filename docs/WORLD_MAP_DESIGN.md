# ワールドマップ設計書

## マップ全体構成

### 方角
- 画面上方：北
- 画面下方：南
- 画面左：西
- 画面右：東

### マップサイズ（タイル単位）
- 幅：200タイル（6400ピクセル）
- 高さ：150タイル（4800ピクセル）
- タイルサイズ：32×32ピクセル

### 地形レイヤー構成
1. **地面レイヤー** - 草原、砂、雪、水など基本地形
2. **装飾レイヤー** - 花、石、小道具
3. **建物レイヤー** - 家、城、遺跡
4. **オブジェクトレイヤー** - 木、岩、崖
5. **コリジョンレイヤー** - 通行不可エリア

## 12地域の詳細配置

### 座標系
- 原点(0, 0)はマップ左上
- 座標はタイル単位

## 1. ティウム（始まりの村）

**位置**: 中央やや西寄り  
**座標範囲**: X: 70-90, Y: 70-85  
**地形**: 草原、森林  

### 構成要素
- 木造の民家 × 8軒
- エマの家（主人公の家）× 1
- 村長の家 × 1
- 畑 × 3か所
- 井戸 × 2
- 小道（村内通路）
- 村の入口（南側）
- 森への道（北側）

### 特徴
- ゲーム開始地点
- 素朴で温かみのある村
- 王都のような豪華さはない
- 自然に囲まれた平和な雰囲気

## 地域間の接続

### 街道
- ティウム ↔ ウェントラン（西）
- ティウム ↔ 星晶鉱山（東）
- 星晶鉱山 ↔ レギーア（東）
- レギーア ↔ アルゲンツ（北）
- ウェントラン ↔ ウラマリー（南）

### 橋
- 川を渡る橋 × 5か所
- 島への橋（ルナムレモ）

### 船
- ウラマリー → ルナムレモ
- ウラマリー → ステラロクス

### 通行制限
- 山脈：通行不可（特定の峠を除く）
- 海・深い川：船が必要
- エクリニグプ：ストーリー進行後に解放

## カメラとスクロール

### カメラ設定
- プレイヤーを中心に追従
- スムーズスクロール
- ズーム可能（×1.0〜×2.0）

### マップ境界
- マップの端ではカメラが止まる
- プレイヤーは境界を超えられない

## 地域名表示

### トリガー
- 地域のArea2Dに入ったとき
- 画面中央上部に地域名を表示
- 2秒間表示後フェードアウト

### 表示形式
```
┌──────────────┐
│   ティウム    │
│ 始まりの村   │
└──────────────┘
```
