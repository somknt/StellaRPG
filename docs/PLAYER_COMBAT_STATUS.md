### 1. 主人公ステータス設計 ✅

**初期値（Lv.1）:**
- HP: 100
- 攻撃力: 15
- 防御力: 5
- 会心率: 5%
- SP: 未解放

**最終値（Lv.40）:**
- HP: 900
- 攻撃力: 132
- 防御力: 44
- 会心率: 5%〜（装備で上昇）
- 最大SP: 100

**成長計算式:**
```
HP = 100 + 21 × (level - 1)
攻撃力 = 15 + 3 × (level - 1)
防御力 = 5 + 1 × (level - 1)
```

### 2. 星力（SP）システム設計 ✅

**解放条件:**
- ストーリー進行でフードを被った星の民と出会う
- 修行イベントで星力の操作を習得
- 魔法陣の瞬間展開を習得

**仕様:**
- 最大SP: 100（固定）
- 初期SP: 100（戦闘開始時満タン）
- 回復: 時間経過、休息、アイテム
- 消費: 魔法陣の展開

**魔道具との違い:**
| 項目 | 魔法陣 | 魔道具 |
|---|---|---|
| 動力源 | 主人公のSP | 魔道具の魔法陣 |
| 習得 | 知識が必要 | 持つだけで使用可能 |
| 制限 | SP消費 | クールダウン |

---

### 3. 戦闘システム設計 ✅

#### 攻撃手段

**剣:**
- 通常攻撃（1.0倍）
- 強攻撃（1.5倍、スタミナ20消費）
- 範囲攻撃（0.8倍、スタミナ30消費）

**魔道具:**
- 誰でも使用可能
- クールダウンで制限
- 主人公のSPは消費しない

**魔法陣:**
- 修行後に瞬間展開可能
- SPを消費
- 攻撃・補助・探索の3種類

#### ダメージ計算式

**基本式:**
```
最終ダメージ = max(1, floor((攻撃力 + 武器威力) × 補正 - 防御力))
```

**剣:**
```
ダメージ = max(1, floor((基礎攻撃力 + 武器威力) × タイプ補正 × 会心補正 × 属性補正 - 防御力))
```

**魔道具:**
```
ダメージ = max(1, floor((基礎攻撃力×0.5 + 魔道具威力) × 属性補正 × 会心補正 - 防御力))
```

**魔法陣:**
```
ダメージ = max(1, floor(魔法威力 × 熟練度補正 × 属性補正 - 防御力))
```

**熟練度補正:**
- 段階3: 1.0倍
- 段階4: 1.2倍

### 4. 属性システム設計 ✅

**属性の種類:**
- 無、炎、水、風、雷、光、闇

**相性:**
- 弱点: 2.0倍ダメージ
- 通常: 1.0倍
- 耐性: 0.5倍

**相性表:**
- 炎 → 風（強）、水（弱）
- 水 → 炎（強）、雷（弱）
- 風 → 雷（強）、炎（弱）
- 雷 → 水（強）、風（弱）
- 光 ⇔ 闇（相互に強）

---

### 5. 防御システム設計 ✅

**回避:**
- スタミナ20消費
- 無敵時間0.3秒
- クールダウン0.5秒

**パリィ:**
- ジャストガードで敵をスタン
- 受付時間0.2秒
- 成功で敵が1.5秒スタン
- 失敗でダメージ

**スタミナ:**
- 最大値: 100
- 回復速度: 10/秒
- 消費: 回避20、ダッシュ5/秒、強攻撃20

## 💡 実装時の注意事項

### データとロジックの分離

- ステータスはJSONで管理
- バランス調整はファイル編集のみで完結
- ハードコーディングを避ける

### 段階的実装

1. 最小限の機能で動作確認
2. 基本戦闘システムの実装
3. 高度な機能の追加
4. バランス調整

### テストプレイ重視

- 早い段階で実際にプレイ
- 数値は暫定値として扱う
- フィードバックを反映

### ストーリー連動への配慮

- 星力は最初から使用できない
- 魔法陣は修行後に解放
- ストーリーフラグで機能を制御
