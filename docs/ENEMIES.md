## 1. 敵キャラクターの基本方針

### 設計理念

『星の子』では、敵を単純に「強さ」で分類するのではなく、**「なぜその敵が存在しているのか」**を重視します。

#### 重要な原則

✅ **背景の重視**
- 各敵には生態、歴史、所属組織、星喰いとの関係などの背景を持たせる
- 敵の存在理由を明確にする

✅ **多様な戦闘スタイル**
- 移動方法、攻撃方法、行動AI、弱点を敵ごとに変化させる
- 2D見下ろし型アクションに適した設計

✅ **段階的な難易度**
- 序盤から終盤まで、プレイヤーの成長に合わせた敵配置
- 地域ごとに異なる難易度設定

✅ **魔法陣習得による攻略の変化**
- 主人公が魔法陣を習得することで、敵の攻略方法が増える
- 探索要素との連動

## ① 野生生物・通常魔物

### 概要

大陸の森、草原、砂漠、雪原などに自然に生息する生物。星喰いとは直接関係なく、世界の生態系を構成している。すべてが凶暴なわけではなく、近づいたときだけ攻撃する生物や、プレイヤーから逃げる生物も存在する。

### ゲーム内での役割

- 序盤の戦闘チュートリアル
- 基本的な敵AIの学習
- 素材収集
- 地域ごとの生態系の表現
- 星喰いに侵された個体との比較

---

### 🐺 草原狼

**分類**: 野生生物  
**区分**: 通常敵  
**出現地域**: ウェントラン（草原）

#### 外見の特徴
- 灰色の毛並み
- 体長約1メートル
- 鋭い牙と爪
- 2〜4匹の群れで行動

#### 攻撃方法
- **噛みつき**: 接近して噛みつく（近接攻撃）
- **飛びかかり**: 距離を詰めて飛びかかる（中距離攻撃）
- **連続攻撃**: 2回連続で噛みつく

#### 行動AI
- **AIタイプ**: 追跡型・集団型
- **基本動作**:
  1. PATROL: 巡回
  2. ALERT: プレイヤーを発見（発見範囲: 5タイル）
  3. CHASE: 追跡開始
  4. ATTACK: 攻撃範囲内で攻撃
  5. RETURN: 一定距離で追跡中止、元の位置へ戻る

#### 弱点
- 炎属性に弱い
- 単体では弱いが群れで強化される

#### ストーリーとの関係
- 特になし（自然の生態系）
- 序盤の戦闘チュートリアル対象

### 🐇 角ウサギ

**分類**: 野生生物  
**区分**: 通常敵（弱小）  
**出現地域**: ティウム周辺

#### 外見の特徴
- 白い毛並み
- 頭部に小さな角
- 小型で素早い
- 単独または2匹程度で行動

#### 攻撃方法
- **角突進**: 直線的に突進して角で攻撃

#### 行動AI
- **AIタイプ**: 突進型・逃走型
- **基本動作**:
  1. IDLE: 草を食べている
  2. ALERT: プレイヤーを発見
  3. FLEE: 逃げる（基本的に非戦闘）
  4. ATTACK: 追い詰められた場合のみ反撃

#### 弱点
- HPが非常に低い
- すべての属性に普通

#### ストーリーとの関係
- 平和なティウムの生態系を表現
- 初心者向けの練習対象

### 🐗 森イノシシ

**分類**: 野生生物  
**区分**: 通常敵  
**出現地域**: ルナエビーナ周辺の森

#### 外見の特徴
- 茶色の毛並み
- 大きな牙
- 筋肉質な体
- 単独行動

#### 攻撃方法
- **直線突進**: 一直線に突進（高威力）
- **体当たり**: 接近して体当たり

#### 行動AI
- **AIタイプ**: 突進型
- **基本動作**:
  1. IDLE: うろうろしている
  2. ALERT: プレイヤーを発見
  3. CHARGE: 突進準備（0.5秒）
  4. ATTACK: 直線突進
  5. STUN: 突進後、壁や岩に衝突すると一時的に動けない

#### 弱点
- 突進を回避すると隙ができる
- 側面からの攻撃に弱い

#### ストーリーとの関係
- 森の生態系を表現
- 回避の重要性を学ぶ

### 🦂 砂蠍

**分類**: 野生生物  
**区分**: 通常敵  
**出現地域**: ウィズデゼール（砂漠）

#### 外見の特徴
- 黄色い外殻
- 大きなハサミ
- 毒を持つ尾
- 砂に半分埋まっていることが多い

#### 攻撃方法
- **毒針**: 尾を振って毒針攻撃（毒状態付与）
- **ハサミ攻撃**: ハサミで挟む

#### 行動AI
- **AIタイプ**: 防御型
- **基本動作**:
  1. HIDE: 砂に埋まって待機
  2. ALERT: プレイヤーが近づくと出現
  3. ATTACK: ハサミ攻撃と毒針を使い分け
  4. DEFENSE: 攻撃を受けると一時的に外殻を硬化

#### 弱点
- 水属性に弱い
- 背後からの攻撃に弱い

#### ストーリーとの関係
- 砂漠の危険性を表現
- 毒状態異常のチュートリアル

## ③ 星喰い侵蝕生物

### 概要

星喰いの影響によって変異した生物。もともとは通常の動物や植物だったものが、異常な星力の影響で凶暴化している。通常個体とは異なる攻撃方法や特殊能力を持つ。

### 星喰い侵蝕度システム ✅ 重要

| 侵蝕度 | 外見 | 能力 | 出現時期 |
|---|---|---|---|
| **Ⅰ: 初期侵蝕** | 目や体の一部が黒く変色 | 通常種より攻撃的、攻撃力少し上昇 | 序盤〜 |
| **Ⅱ: 中期侵蝕** | 体に黒い結晶や模様 | 攻撃パターン増加、特殊攻撃 | 中盤〜 |
| **Ⅲ: 完全侵蝕** | 元の姿から大きく変異 | 特殊能力、非常に高い戦闘能力 | 終盤 |

### ゲーム内での役割

- 星喰いの恐ろしさを表現する
- 汚染地域の危険度を示す
- 世界の異変を戦闘を通して伝える
- ストーリー進行によるフィールド変化を表現する

## 4. 敵AIシステム

### 基本AIタイプ

敵を個別に実装するのではなく、共通のAI行動パターンを用意し、敵ごとに組み合わせる。

| AIタイプ | 動作 | 該当する敵 |
|---|---|---|
| **追跡型** | プレイヤーを発見すると追いかける | 草原狼、盗賊、白暁歩兵 |
| **突進型** | 一定距離から直線的に突進する | 森イノシシ、採掘機兵 |
| **遠距離型** | 距離を保ちながら攻撃する | 炎精、盗賊弓兵、白暁弓兵 |
| **飛行型** | 地上障害物の一部を無視して移動 | 洞窟コウモリ、月光蝶 |
| **防御型** | 攻撃を防ぎながら接近する | 白暁盾兵、重装傭兵 |
| **集団型** | 仲間と連携して戦う | 草原狼、盗賊 |
| **固定砲台型** | 移動せず範囲内の敵を攻撃 | 星紋砲台、暴走防衛兵 |
| **特殊型** | 属性攻撃・状態異常・形態変化など | 影喰い、虚無獣、ボス |
| **擬態型** | 周囲に溶け込んで待ち伏せ | 晶石精霊、砂蠍 |
| **非攻撃型** | 基本的に攻撃しない | 星光スライム、月光蝶 |
| **ボス型** | 複雑な攻撃パターン、段階変化 | 各ボス |

### 基本状態

敵AIの状態遷移：

```
IDLE（待機）
  ↓
PATROL（巡回）
  ↓
ALERT（警戒）← プレイヤー発見
  ↓
CHASE（追跡）
  ↓
ATTACK（攻撃）← 攻撃範囲内
  ↓
STUN（ひるみ）← ダメージを受ける
  ↓
RETURN（帰還）← プレイヤーが遠ざかる
または
FLEE（逃走）← HPが低下
  ↓
DEAD（死亡）
```

すべての敵が全状態を持つ必要はない。
