## 1. 星力とは

### 1.1 星力の定義

**星力（SP: Star Power）**は、星の民が持つ固有の力です。

主人公は人間と星の民のハーフであるため、体内に星力を持っていますが、**物語序盤は使い方を知りません**。

### 1.2 星力と魔道具の違い

| 項目 | 星力による魔法陣 | 魔道具 |
|---|---|---|
| **動力源** | 主人公の体内の星力 | 魔道具に刻まれた魔法陣 |
| **SP消費** | 消費する | 消費しない |
| **使用条件** | 星力解放 + 知識習得 | 持っているだけ |
| **制限** | SP残量、クールダウン | クールダウン、耐久度 |
| **柔軟性** | 高い（多様な魔法陣） | 中（固定された効果） |
| **成長** | 熟練度で威力上昇 | 変化なし |

### 1.3 星力習得の重要な原則

**❌ 採用しない演出：**
- 危機的状況で突然覚醒
- 無意識に魔法陣を展開
- 感情の爆発で星力が暴走

**✅ 採用する演出：**
- フードを被った星の民との出会い
- 段階的な修行と理解
- 知識を学んで魔法陣を習得
- 意識的に星力を制御

## 2. 星力習得段階

### 2.1 段階システム

星力の習得は**5段階**に分かれています。

各段階はレベルアップではなく、**ストーリーイベントや修行**によって解放されます。

| 段階 | 名称 | 解放条件 | できること |
|---|---|---|---|
| **段階0** | 未解放 | 初期状態 | 星力を使用できない |
| **段階1** | 星力感知 | 師匠との出会い | 星力の存在を感じられる |
| **段階2** | 星力操作 | 修行イベント1 | 体内の星力を操作できる |
| **段階3** | 魔法陣展開 | 修行イベント2 | 魔法陣を瞬時に展開可能 |
| **段階4** | 星紋熟練 | 高度な修行 | 高度な魔法陣、連続展開 |

### 2.2 段階別の詳細

#### 段階0：未解放

**状態：**
- 星力を使用できない
- UI上にSPゲージは表示されない
- 魔法陣は使用不可（魔道具は使用可能）

**制限：**
- 星力による攻撃・補助は一切不可
- 探索で魔法陣が必要な場合は魔道具を使用

---

#### 段階1：星力感知

**解放イベント：**
- 物語の途中で「フードを被った星の民」と出会う
- 主人公の星力の存在を指摘される
- 星力の感知方法を教わる

**できること：**
- 星力の存在を感じられる
- 他者の星力を感知できる
- 魔法陣の残留星力を見ることができる

**制限：**
- まだ戦闘では使用できない
- SPゲージは表示されるが使用不可
- 探索での簡単な感知のみ

**ストーリー的意義：**
- 主人公が自分の出自に気づく
- 星の民との関わりを深める
- 星力の基礎知識を学ぶ

---

#### 段階2：星力操作

**解放イベント：**
- 師匠との修行イベント1
- 体内の星力を動かす訓練
- 星力を手のひらに集める練習

**できること：**
- 体内の星力を意識的に操作
- 手のひらに星力を集めて光を出す
- 星力による治癒（星の民の基本能力）

**制限：**
- 戦闘での攻撃魔法陣はまだ使えない
- 補助魔法陣の一部（星灯陣など）のみ使用可能
- SP消費は小さい行動のみ

**使用可能な魔法陣：**
- 星灯陣（照明）
- 治癒（星力の基本能力、魔法陣ではない）

---

#### 段階3：魔法陣展開

**解放イベント：**
- 師匠との修行イベント2
- 魔法陣の構造を学ぶ
- 瞬時に魔法陣を展開する訓練

**できること：**
- 魔法陣を瞬時に展開
- 攻撃魔法陣の使用
- 補助魔法陣の使用
- 戦闘での星力活用

**制限：**
- 基本的な魔法陣のみ
- 高度な魔法陣は未習得
- 熟練度補正なし（倍率1.0）

**使用可能な魔法陣：**
- 光弾陣、風刃陣、火炎陣（基本攻撃）
- 星盾陣、星灯陣、星風陣（基本補助）
- その他、習得した魔法陣

---

#### 段階4：星紋熟練

**解放イベント：**
- 高度な修行イベント
- 古代遺跡での魔法陣研究
- 実戦経験の蓄積

**できること：**
- 高度な魔法陣の習得
- 魔法陣の連続展開
- 魔法陣の威力上昇（倍率1.2）
- 複雑な魔法陣の組み合わせ

**強化内容：**
- 全魔法陣の威力+20%
- クールダウン-10%
- SP消費-10%（一部魔法陣）

**使用可能な魔法陣：**
- 氷結陣、雷撃陣、星光陣（高度な攻撃）
- 星縛陣、星導陣（高度な補助）
- 全ての基本魔法陣（強化版）

## 3. SP最大値と成長

### 3.1 最大SP計算式

```
最大SP = 50 + 6 × (level - 1)
```

**例：**
- Lv.1: 50
- Lv.10: 104
- Lv.20: 164

#### 攻撃魔法陣の詳細

**光弾陣：**
- 最も基本的な攻撃魔法陣
- 小さな光の弾を発射
- SP消費が少なく連射可能
- 威力は低いが汎用性が高い

**風刃陣：**
- 風の刃を飛ばす
- 貫通効果がある
- 複数の敵を巻き込める

**火炎陣：**
- 火球を発射
- 炎上状態を付与する可能性
- 風属性の敵に有効

**氷結陣：**
- 氷の弾を発射
- 氷結状態を付与する可能性
- 炎属性の敵に有効

**雷撃陣：**
- 雷を放つ
- 高威力だがSP消費が大きい
- 水属性の敵に有効

**星光陣：**
- 最強の光属性魔法陣
- 巨大な光の槍を放つ
- SP消費が非常に大きい
- 闇属性の敵に非常に有効

- 星力で体を軽くする
- 一定時間、移動速度が大幅上昇
- 探索や戦闘で有効

**星導陣：**
- 古代の魔導装置を起動
- 謎解きやギミックで使用

## 5. 魔法陣の習得

### 5.1 習得方法

**魔法陣の習得には知識が必要です。**

星力を解放しただけでは、すべての魔法陣を使用できません。

#### 習得方法の種類

| 方法 | 説明 | 例 |
|---|---|---|
| **修行** | 師匠から教わる | 光弾陣、風刃陣、星盾陣 |
| **書物** | 書物を読んで習得 | 火炎陣、星風陣 |
| **遺跡** | 古代遺跡で発見 | 氷結陣、星縛陣、星導陣 |
| **師匠（高度）** | 高度な修行で習得 | 雷撃陣 |
| **イベント** | 特殊なイベントで習得 | 星光陣 |

### 5.2 習得の流れ

```
1. 星力段階3に到達
   ↓
2. 魔法陣の知識を入手
   ↓
3. 魔法陣を習得
   ↓
4. 戦闘や探索で使用可能
```

### 5.3 習得条件

**基本条件：**
- 星力段階が条件を満たしている
- 知識を入手している

**追加条件（魔法陣による）：**
- 一定レベル以上
- 特定のクエスト完了
- 特定のアイテム所持

## 6. ダメージ計算

### 6.1 魔法陣のダメージ計算式

```
最終ダメージ = max(1, floor((基礎攻撃力 + 魔法陣威力) × 熟練度補正 × 属性補正 - 敵の防御力))
```

**注意：**
- 基礎攻撃力は主人公の攻撃力ステータス**ではない**
- 基礎攻撃力 = 0（魔法陣は威力のみで計算）

**簡略版：**
```
最終ダメージ = max(1, floor(魔法陣威力 × 熟練度補正 × 属性補正 - 敵の防御力))
```

### 6.2 熟練度補正

| 段階 | 熟練度補正 | 説明 |
|---|---|---|
| 段階3 | 1.0倍 | 基本威力 |
| 段階4 | 1.2倍 | 熟練による強化 |

### 6.3 属性補正

| 相性 | 補正 | 説明 |
|---|---|---|
| **弱点** | 2.0倍 | 敵の弱点属性 |
| **通常** | 1.0倍 | 相性なし |
| **耐性** | 0.5倍 | 敵の耐性属性 |

### 6.4 ダメージ計算例

#### 例1：光弾陣（段階3、弱点なし）

```
主人公: Lv.15、段階3
魔法陣: 光弾陣（威力20）
敵: 草原狼（防御力3）

ダメージ = floor(20 × 1.0 × 1.0 - 3)
         = floor(20 - 3)
         = 17
```

#### 例2：火炎陣（段階4、弱点）

```
主人公: Lv.25、段階4
魔法陣: 火炎陣（威力35）
敵: 氷精（防御力12、炎が弱点）

ダメージ = floor(35 × 1.2 × 2.0 - 12)
         = floor(84 - 12)
         = 72
```

#### 例3：雷撃陣（段階4、通常）

```
主人公: Lv.30、段階4
魔法陣: 雷撃陣（威力50）
敵: 黒蝕狼（防御力26）

ダメージ = floor(50 × 1.2 × 1.0 - 26)
         = floor(60 - 26)
         = 34
```

## 7. SP回復システム

### 7.1 自然回復

**戦闘外での自然回復：**

| 条件 | 回復量 |
|---|---|
| **5秒経過後** | 毎秒1SP回復 |
| **最大値到達** | 回復停止 |

**戦闘中の自然回復：**
- なし（戦闘中は回復しない）

### 7.2 アイテムによる回復

| アイテム | 回復量 | 入手方法 |
|---|---|---|
| **SP回復薬（小）** | 40SP | 店舗、ドロップ |
| **SP回復薬（中）** | 100SP | 店舗、宝箱 |
| **SP回復薬（大）** | 200SP | 店舗、ボスドロップ |

**注意：**
- 最大SPを超えて回復しない
- 戦闘中にも使用可能

### 7.3 施設での回復

| 施設 | 回復量 | コスト |
|---|---|---|
| **星の泉** | 全回復 | 無料 |
| **宿屋** | 全回復 | 有料（地域による） |
| **セーブポイント** | 全回復 | 無料 |

### 7.4 SP回復の計算例

#### 例1：自然回復

```
現在SP: 50 / 164（Lv.20）
戦闘終了後5秒経過

5秒後: 50 + (1 × 1) = 51
6秒後: 51 + 1 = 52
7秒後: 52 + 1 = 53
...
214秒後: 164（最大値到達）
```

#### 例2：回復薬使用

```
現在SP: 30 / 164（Lv.20）
SP回復薬（中）使用

回復後: 30 + 100 = 130
```

#### 例3：最大値超過

```
現在SP: 150 / 164（Lv.20）
SP回復薬（大）使用

計算: 150 + 200 = 350
実際: 164（最大値で停止）
```

## 8. 手描き魔法陣と瞬間展開

### 8.1 手描き魔法陣（段階0〜2）

**使用条件：**
- 特定の場所でのみ使用可能
- 謎解きやイベント専用
- 戦闘中は使用不可

**制限：**
- 時間がかかる（数秒）
- 動きながら展開できない
- SP消費は同じ

**用途：**
- ストーリーイベント
- 謎解き
- 古代遺跡のギミック

---

### 8.2 瞬間展開（段階3〜4）

**使用条件：**
- 星力段階3以降
- 習得済みの魔法陣
- SP残量が十分

**特徴：**
- ボタン一つで瞬時に展開
- 戦闘中に使用可能
- 移動しながら展開可能

**使用方法：**
```
1. 魔法陣選択（ショートカット or メニュー）
   ↓
2. ボタン押下
   ↓
3. 即座に魔法陣展開
   ↓
4. SP消費、クールダウン開始
```

---

### 8.3 手描きと瞬間展開の比較

| 項目 | 手描き | 瞬間展開 |
|---|---|---|
| **段階** | 0〜2 | 3〜4 |
| **展開時間** | 数秒 | 即座 |
| **戦闘使用** | ❌ | ✅ |
| **移動中** | ❌ | ✅ |
| **用途** | 謎解き | 戦闘・探索 |
| **SP消費** | 同じ | 同じ |
