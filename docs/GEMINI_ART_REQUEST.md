## 📝 Geminiへのプロンプトテンプレート

### プロンプト1: プロジェクト全体の説明

```
# ゲームプロジェクト「星の子 (Hoshi no Ko)」のアートアセット作成依頼

## ゲーム概要
- ジャンル: 2Dオープンワールド・ファンタジーRPG
- 視点: 見下ろし型（トップダウン）
- 雰囲気: ファンタジー、星と魔法の世界
- エンジン: Godot 4.3

## 世界観
主人公は人間と「星の民」のハーフで、体内に眠る星力を目覚めさせながら冒険します。
世界は美しい星空と自然に満ちていますが、「星喰い」という謎の侵蝕が広がっています。

## アートスタイル
- スタイル: 2Dドット絵 または HD 2Dイラスト（どちらか選んでください）
- カラーパレット: 青・紫・白を基調とした星空の色彩
- 雰囲気: 柔らかく神秘的、でも冒険心をくすぐる

## 技術仕様
- ドット絵の場合: 32x32 または 32x48 ピクセル
- HD絵の場合: 128x128 または 128x192 ピクセル
- ファイル形式: PNG（透過背景）
- フレームレート: 8-12 FPS（アニメーション）

次に、具体的なキャラクターやエフェクトのアセットを依頼します。
まず、このプロジェクトの世界観とアートスタイルについて理解できましたか？
```

### プロンプト2: プレイヤーキャラクター（最重要）

```
# プレイヤーキャラクター「主人公」のスプライト作成

## キャラクター設定
- 年齢: 16-18歳
- 性別: [男性/女性/中性的]（お任せします）
- 髪色: 黒に近い茶色（ダークブラウン）
- 瞳: オレンジに近い黄色（星の民の特徴）
- 服装: 旅人の服装、茶色っぽい服
- 武器: 小さな剣（腰に装備）
- 雰囲気: 純粋で優しいが、内に秘めた強さがある

## 必要なアセット

### 1. 立ち絵（アイドル状態）
- 正面を向いている
- 1-2コマのアニメーション（呼吸や風になびく髪）
- サイズ: 32x48ピクセル（ドット絵）または 128x192ピクセル（HD）

### 2. 歩行アニメーション
- 4方向: 上、下、左、右
- 各方向3-4コマ
- サイズ: 32x48ピクセル（ドット絵）または 128x192ピクセル（HD）
- スプライトシート形式で作成してください

### 3. 攻撃アニメーション
- 正面向き（1方向でOK）
- 3-4コマ（剣を振る動作）
- サイズ: 32x48ピクセル（ドット絵）または 128x192ピクセル（HD）

### 4. 魔法陣使用アニメーション
- 正面向き（1方向でOK）
- 3-4コマ（手を前に出して魔法陣を展開）
- サイズ: 32x48ピクセル（ドット絵）または 128x192ピクセル（HD）

## 出力形式
- PNG形式（透過背景）
- スプライトシート: 横に並べて1枚の画像として出力
  例: walk_down_frame1.png, walk_down_frame2.png, walk_down_frame3.png
  または walk_down_spritesheet.png（横並び）

## カラーパレット
- 髪: #3d2817（黒に近い茶色）
- 瞳: #ffb347（オレンジがかった黄色）
- 服: #8b6f47（茶色）
- 肌: #ffcdb2（明るい肌色）

よろしくお願いします！
```

## 🎨 Geminiへの追加指示

各プロンプトの最後に以下を追加すると良いです：

```
## 補足
- 画像は必ず透過PNG形式で出力してください（背景タイル以外）
- スプライトシートの場合、横一列に並べてください
- ファイル名は英語で分かりやすく（例: player_walk_down.png）
- 各フレームは等間隔で配置してください
```

## 📝 依頼時の注意点

1. **一度に1つずつ**: すべてを一度に依頼すると混乱します。プロンプト1→2→3の順に。

2. **サンプル画像を要求**: 最初に1つだけサンプルを作ってもらい、スタイルを確認。

3. **修正は具体的に**: 「もっと明るく」ではなく「色を#7cb342に変更」と指定。

4. **スプライトシートの形式を明確に**: 横並び、何コマ、など詳しく指定。

5. **テストファイルで確認**: 作成してもらったらすぐGodotに読み込んで確認。
