# 敵キャラクター画像生成プロンプト

## 【全体コンセプト】
2D RPG用の敵キャラクター。トップダウン視点（真上から見下ろし）で、
プレイヤーと戦うモンスターたち。ファンタジー世界観に合った可愛らしくも脅威的なデザイン。

---

## 【共通仕様】

### 画像設定
- **視点**: トップダウン（真上から見下ろし）
- **サイズ**: 128×128ピクセル（基本）、大型敵は256×256ピクセル
- **スタイル**: 高品質なアニメ調、ピクセルアート風も可
- **背景**: 透明（PNG形式）
- **アニメーション**: 2〜3コマ（オプション）

### デザインポイント
- 敵とすぐにわかる脅威的な雰囲気
- でも可愛らしさも残す（星の子の世界観）
- 影を含めて描画
- 適度にデフォルメされたデザイン

---

## 🐰 角ウサギ (Horn Rabbit)

### 基本情報
- **レベル**: 1
- **カテゴリ**: 野生
- **地域**: ティウム周辺（始まりの村）
- **特徴**: 臆病で基本的に逃げるが、追い詰められると反撃

### ChatGPT用プロンプト
```
トップダウン2D RPG用の敵キャラクター「角ウサギ」を作成してください。

【仕様】
- サイズ：128×128ピクセル
- 視点：真上から見下ろし（トップダウン）
- スタイル：高品質なアニメ調、可愛らしいがやや脅威的
- 背景：透明（PNG形式）

【デザイン】
- **種族**：小型の茶色いウサギ
- **特徴**：額の中央に小さな一本の角（白っぽい色）
- **サイズ**：小型（体長30cm程度の印象）
- **色**：明るい茶色の毛皮、お腹は白っぽい
- **耳**：長くて大きな耳（ピンと立っている）
- **表情**：少し警戒した表情、目は丸くて黒い
- **ポーズ**：地面に四つ足でいる、ジャンプの準備姿勢
- **影**：キャラクターの下に柔らかい影

【雰囲気】
- 臆病だが角で反撃する準備ができている
- 野生の小動物の警戒心
- 可愛いが敵として認識できるデザイン
- 初心者が戦う最初の敵にふさわしい

【重要】
- 真上から見た時に立体感がある
- 角が見えるように描く
- ゲーム用なので分かりやすいシルエット
```

### アニメーション版（オプション）
```
先ほどの角ウサギの2コマアニメーションを作成してください。

【コマ1】（128×128px）
- 地面に四つ足でいる状態
- 通常の待機姿勢

【コマ2】（128×128px）
- ジャンプ準備姿勢
- 少し体を縮めて飛び跳ねる直前

同じ角度、同じ位置で描いてください。
背景透明、PNG形式。
```

## ✨ 星光スライム (Starlight Slime)

### 基本情報
- **レベル**: 7
- **カテゴリ**: 精霊
- **地域**: ウェントラン（草原地帯）
- **特徴**: 星力が集まって生まれた。攻撃されなければ襲ってこない

### ChatGPT用プロンプト
```
トップダウン2D RPG用の敵キャラクター「星光スライム」を作成してください。

【仕様】
- サイズ：128×128ピクセル
- 視点：真上から見下ろし（トップダウン）
- スタイル：高品質なアニメ調、幻想的で美しい
- 背景：透明（PNG形式）

【デザイン】
- **形状**：丸いゼリー状のスライム
- **色**：淡い水色〜青白色、半透明感
- **特殊効果**：体内に小さな星の光が複数浮かんでいる
  - 星は金色や白色で輝いている
  - 3〜5個の小さな星が体内に浮遊
- **質感**：ぷるぷるした半透明のゼリー感
- **サイズ**：中型（直径40cm程度の印象）
- **輪郭**：柔らかくぼんやりした境界線
- **光**：体全体がほのかに発光
- **影**：柔らかく淡い影

【雰囲気】
- 神秘的で美しい
- 敵というより精霊的な存在感
- 星の力が結晶化した生命体
- 攻撃的ではないが脅威となる存在
- 幻想的なグロー効果

【重要】
- 半透明感を表現
- 体内の星の輝きを美しく描く
- 真上から見てもスライムとわかる形
- ゼリー状の質感を意識
```

### アニメーション版（オプション）
```
先ほどの星光スライムの3コマアニメーションを作成してください。

【コマ1】（128×128px）
- 通常状態
- 体内の星が均等に配置

【コマ2】（128×128px）
- 少し伸びた状態
- 体内の星が少し移動

【コマ3】（128×128px）
- 少し縮んだ状態
- 体内の星がさらに移動（ぷるぷる感）

同じ角度、同じ位置で描いてください。
背景透明、PNG形式。
ぷるぷる動いている感じを表現。
```

## 【アニメーション仕様】

### 待機アニメーション
- **フレーム数**: 2〜3コマ
- **ループ**: 繰り返し再生
- **動き**: 呼吸、ぷるぷる、体の揺れなど

### 攻撃アニメーション（オプション）
- **フレーム数**: 3〜4コマ
- **動き**: 突進、ジャンプ、攻撃姿勢など

## 【生成手順】

### ステップ1: 角ウサギを生成
1. 上記の角ウサギプロンプトをコピー
2. ChatGPTに貼り付け
3. 画像を確認
4. 気に入ったら保存

### ステップ2: 星光スライムを生成
1. 星光スライムプロンプトをコピー
2. ChatGPTに貼り付け
3. 画像を確認
4. 気に入ったら保存

### ステップ3: アニメーション版（オプション）
1. 各キャラのアニメーションプロンプトを使用
2. 複数コマを生成
3. 各コマを個別に保存

### ステップ4: 配置
1. ファイル名を規則に従って変更
2. `js_version/assets/enemies/` に配置
3. ゲームで確認
