今すぐコピペ！品質改善プロンプト集
====================================================================

低品質な画像が来たら、以下をそのままコピペしてください。


====================================================================
【1】ドット絵スタイルにしてほしい（最重要）
====================================================================

これはドット絵（ピクセルアート）ではありません。

スーパーファミコンやゲームボーイアドバンスの
クラシックゲームのようなドット絵で作り直してください。

要件:
- 32x48ピクセルのドット絵
- すべてのピクセルがくっきり見える
- アンチエイリアシングなし
- ピクセルパーフェクト

参考ゲーム:
- ファイナルファンタジー6
- クロノトリガー
- ポケットモンスター（GBA版）
- スターデューバレー

キャラクター:
- 髪: #3d2817（黒茶色）
- 瞳: #ffb347（オレンジ黄色）
- 服: #8b6f47（茶色）

サイズ: 96x48px（32x48が3コマ横並び）
透過PNG


====================================================================
【2】もっとディテールを追加してほしい
====================================================================

ディテールを追加して、プロフェッショナルレベルにしてください。

追加要素:

1. シェーディング（陰影）
   - 髪: 3色のグラデーション
   - 瞳: 輝きを表現
   - 服: 明暗の表現
   - 肌: 立体感

2. アウトライン
   - 黒い輪郭線を明確に
   - 顔のパーツも強調

3. 細部
   - 髪の流れ
   - 服のシワ
   - 剣のディテール

参考: クロノトリガーの主人公クロノのスプライト


====================================================================
【3】色を正確にしてほしい
====================================================================

色を正確に修正してください。

正確なHEXコード:
- 髪: #3d2817
- 瞳: #ffb347
- 服: #8b6f47
- 肌: #ffcdb2

これらの色を正確に使用してください。


====================================================================
【4】サイズを直してほしい
====================================================================

サイズが正確ではありません。

正確なサイズ:
- 1コマ: 32px（横）× 48px（縦）
- 3コマ合計: 96px（横）× 48px（縦）

リサイズせず、最初から96x48pxで作成してください。


====================================================================
【5】もっと高品質にしてほしい
====================================================================

商用ゲームで使用できるプロフェッショナルレベルの
ドット絵に改善してください。

要件:
✓ ピクセルパーフェクト
✓ 3-4色のシェーディング
✓ くっきりした輪郭
✓ 細かいディテール
✓ 滑らかなアニメーション

参考品質:
- スターデューバレー
- Celeste
- Undertale

キャラクター設定は変更なし。


====================================================================
【6】アニメーションを改善してほしい
====================================================================

歩行アニメーションを改善してください。

理想的な歩行サイクル:
- コマ1: 左足前、右足後ろ
- コマ2: 両足揃う（中間）
- コマ3: 右足前、左足後ろ

要件:
- 滑らかな動き
- 体の上下動
- 腕の振り

参考: 16ビットRPGの歩行アニメ


====================================================================
【7】全部まとめて改善してほしい
====================================================================

以下の要件をすべて満たすように改善してください:

✓ ドット絵スタイル（ピクセルパーフェクト）
✓ サイズ: 96x48px（32x48が3コマ）
✓ 髪: #3d2817（黒茶、3色シェーディング）
✓ 瞳: #ffb347（オレンジ黄、輝きあり）
✓ 服: #8b6f47（茶色、3色シェーディング）
✓ 透過背景
✓ くっきりした輪郭線
✓ 滑らかなアニメーション
✓ 商用レベルの品質

参考ゲーム: ファイナルファンタジー6、クロノトリガー

====================================================================
【9】別のアプローチ: 手順を指定
====================================================================

以下の手順でドット絵を作成してください:

1. 32x48pxキャンバスを用意
2. キャラクターのシルエットを描く
3. ベース色を塗る（#3d2817、#ffb347、#8b6f47）
4. シェーディングを追加（各色に2-3段階）
5. 黒いアウトラインを整える
6. ディテールを追加（目の輝き、髪の流れ）
7. 3コマ作成して横に並べる（96x48px）

16ビット時代のSNESゲームのような品質で。
