# タイトル画面（トップ画面）デザインプロンプト

## 【ゲーム情報】
- **タイトル**: 星の子（Hoshi no Ko / ほしのこ）
- **ジャンル**: 2Dオープンワールド・ファンタジーRPG
- **世界観**: 魔法陣文明、星の民と人間の対立、復讐と赦しの物語
- **雰囲気**: 温かくも切ない、希望と悲しみが混在

---

## 【タイトル画面コンセプト】

### メインテーマ
**「二つの月が見守る、希望と悲しみの物語」**

- 夜空に浮かぶツインムーン（二つの月）
- 小さな主人公のシルエット
- 星の光が優しく照らす
- 幻想的で美しいが、どこか物悲しい

## 【ChatGPT用プロンプト - タイトル画面】

```
2D RPGゲーム「星の子（Hoshi no Ko）」のタイトル画面を作成してください。

【仕様】
- サイズ：1920×1080ピクセル（16:9の横長）
- スタイル：高品質なアニメ調、幻想的で美麗
- 用途：ゲーム起動時のメイン画面

【構図】
- **背景**：夜空のグラデーション
  - 上部：濃い紺色〜紫色
  - 下部：少し明るい青紫色
  - 無数の星が輝いている
  
- **ツインムーン（二つの月）**：
  - 上部中央やや右に配置
  - 第一の月：通常の満月（白く輝く、クレーターが見える）
  - 第二の月（母星）：やや大きく、青白い不思議な模様
  - 二つの月が並んで浮かぶ幻想的な光景

- **地平線**：
  - 下部に緩やかな丘のシルエット
  - 草原と遠くに見える森
  - 暗いシルエットだが月明かりで輪郭がわかる

- **主人公のシルエット**：
  - 中央やや下、小高い丘の上に立つ小さなシルエット
  - 子供の姿（10歳くらい）
  - 月を見上げている後ろ姿
  - 服は風になびいている
  - 胸の星の宝石がほのかに光っている

- **星の光**：
  - 空から降り注ぐ星の光（ライトパーティクル）
  - 主人公の周りに星の粒子が舞っている
  - 神秘的なグロー効果

【タイトルロゴ位置】
- 上部中央に大きく「星の子」
- その下に小さく英語サブタイトル「Hoshi no Ko」
- （ロゴは後から追加するため、スペースを空けておく）

【色調】
- **夜空**：#1a1a3e（濃紺）〜 #4a4a7a（紫青）のグラデーション
- **月の光**：#ffffff（白）、グロー効果
- **星の光**：#ffd700（金色）、#87ceeb（淡い青）
- **星の粒子**：#ffffe0（淡い黄色）
- **シルエット**：#0a0a0a（黒に近い濃紺）

【雰囲気】
- 美しくも切ない夜の情景
- 希望と悲しみが混在
- 冒険の始まりを予感させる
- 静かで神秘的
- プレイヤーを物語の世界に引き込む

【重要な注意事項】
- タイトルロゴは入れないでください（後から追加します）
- 主人公は小さく、風景の一部として
- 月と星が主役の構図
- 高解像度で美麗に
- ファンタジーRPGらしい神秘性
```

## 【タイトル画面のUI要素】

### メインメニュー（第1階層）
```
┌─────────────────┐
│   ストーリー    │  ← ストーリーモード
├─────────────────┤
│    バトル       │  ← フリーバトルモード
├─────────────────┤
│   せってい      │  ← 設定画面
├─────────────────┤
│   クレジット    │  ← 製作者情報
└─────────────────┘
```

### ストーリーメニュー（第2階層）
「ストーリー」を選択すると表示される：
```
┌─────────────────┐
│   はじめから    │  ← 新規ゲーム開始
├─────────────────┤
│  つづきから     │  ← セーブデータ読み込み
├─────────────────┤
│    もどる       │  ← メインメニューに戻る
└─────────────────┘
```

### バトルメニュー（第2階層）
「バトル」を選択すると表示される：
```
┌─────────────────┐
│   かんたん      │  ← 初心者向け
├─────────────────┤
│   ふつう        │  ← 標準的な難易度
├─────────────────┤
│   むずかしい    │  ← 上級者向け
├─────────────────┤
│    もどる       │  ← メインメニューに戻る
└─────────────────┘
```

### ボタンデザイン
```
半透明の黒背景（rgba(0, 0, 0, 0.6)）
白い文字（#ffffff）
選択時：淡い金色に光る（#ffd700）
ホバー時：少し拡大
星のパーティクルエフェクト

【第1階層】メインメニュー
- ボタンサイズ：大きめ（幅300px、高さ60px）
- 中央に配置
- 4つのボタンが縦に並ぶ

【第2階層】サブメニュー
- ボタンサイズ：中くらい（幅250px、高さ50px）
- 右側に配置（スライドイン）
- 3～4つのボタンが縦に並ぶ
- 「もどる」ボタンは他と区別
```

### メニュー遷移アニメーション
```
メインメニュー → サブメニュー
1. メインメニューが左にスライドアウト
2. サブメニューが右からスライドイン
3. フェード効果で滑らか

サブメニュー → メインメニュー
1. サブメニューが右にスライドアウト
2. メインメニューが左からスライドイン
```

## 【アニメーション案】

タイトル画面に動きをつける場合：

1. **星のきらめき**
   - 星がゆっくり点滅
   - キラキラ光るパーティクル

2. **雲の流れ**
   - 背景の雲がゆっくり流れる

3. **月の輝き**
   - 月が淡く光る（パルス）

4. **主人公の呼吸**
   - シルエットが微妙に動く

5. **星の粒子**
   - 画面全体を星の粒子が舞う

## 【生成手順】

### ステップ1: メイン背景を生成
1. 「タイトル画面」プロンプトをコピー
2. ChatGPTに貼り付け
3. 1920×1080pxで生成
4. 保存：`title_screen.png`

### ステップ2: タイトルロゴを生成
1. 「タイトルロゴ」プロンプトをコピー
2. ChatGPTに貼り付け

### ステップ3: メニューパネルを生成
1. 「メニューボタン背景」プロンプトをコピー
2. ChatGPTに貼り付け
3. 600×400pxで生成
4. 保存：`title_menu_panel.png`

### ステップ4: 配置
1. 各画像を`assets/ui/`フォルダに配置
2. ゲームで確認
