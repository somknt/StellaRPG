====================================================================
よくある問題と解決法
====================================================================

【問題1】ぼやけた画像が来る

原因: AIがドット絵を理解していない

解決法:
「16ビットスタイルのドット絵」
「ピクセルパーフェクト」
「アンチエイリアシングなし」
を強調する


【問題2】色が全然違う

原因: HEXコードを無視している

解決法:
「正確に#3d2817を使用してください」
「このHEXコードから逸脱しないでください」
と強調する


【問題3】サイズが違う（大きすぎる/小さすぎる）

原因: 自動でリサイズしている

解決法:
「正確に96x48ピクセル」
「リサイズしないでください」
「最初から96x48pxで作成」
と強調する


【問題4】のっぺりしている

原因: シェーディングがない

解決法:
「各パーツに3色のシェーディング」
「光源を意識した陰影」
「ディテールを追加」
を依頼する


【問題5】何度やっても品質が低い

原因: Geminiの限界

解決法:
1. 具体的なゲーム名を参考に指定
2. 「商用レベル」「プロフェッショナル」を強調
3. 別のAIツール（DALL-E、Midjourney）を試す
4. 自分でドット絵ツール（Aseprite）を使う
5. フリー素材を探す（OpenGameArt.org）

====================================================================
参考: 高品質ドット絵の条件
====================================================================

プロレベルのドット絵の特徴:

1. ピクセルパーフェクト
   → すべてのピクセルが意図的

2. 限定カラーパレット
   → 各パーツ3-4色

3. 効果的なシェーディング
   → 光源を意識

4. くっきりした輪郭
   → 黒または濃色のアウトライン

5. 読みやすさ
   → 小サイズでも明確

6. 一貫性
   → 全コマ同じスタイル

7. 滑らかなアニメーション
   → 自然な動き


====================================================================
最終的な判断基準
====================================================================

以下をすべて満たせば合格:

✓ 遠目で見てもキャラクターだと分かる
✓ ピクセルがくっきり見える
✓ 色が設定通り
✓ サイズが正確（96x48px）
✓ 透過背景
✓ 3コマで歩行が表現されている
✓ 市販ゲームで使えそうな品質

1つでも✗なら改善依頼を続ける
