====================================================================
Godotへの読み込み
====================================================================

1. Godotで「星の子」プロジェクトを開く

2. assets/characters/ にファイルをドラッグ＆ドロップ

3. ファイルをクリック
   → Import タブ
   → Filter: Nearest
   → Reimport

4. scenes/player/player.tscn を開く

5. AnimatedSprite2D ノードを選択
   → Texture: player_walk_down.png
   → HFrames: 3

6. F5でテスト → プレイヤーが歩く！
