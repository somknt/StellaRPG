# オンラインのアカウント（PC とスマホで同じアカウントを使う）

ゲームのアカウントとセーブデータを、無料のデータベース Supabase に保存します。準備は1回だけです。
準備ができるまでは、アカウントはその端末（ブラウザ）だけに保存されます。

## 保存される物

- ユーザー名
- パスワード：そのままでは保存されません。bcrypt で計算した、元に戻せない値だけが保存されます。
- セーブデータ：
  - プレイヤー名
  - 主人公（男の子・女の子）
  - 装備画面の設定（魔法パレット）
  - バトルコイン
  - クリアの記録・マイベスト

## 準備のしかた

1. **Supabase のアカウントとプロジェクトを作る**
   - https://supabase.com で、無料のアカウントを作ります。
   - 「New project」を押して、プロジェクトを作ります。
     - Name：何でもよい（例 `hoshinoko`）
     - Database Password：自分で決めて、メモしておく
     - Region：Northeast Asia (Tokyo)
     - 「Enable Data API」（Data API を使う）：チェックを入れたままにする（ゲームはこれで関数を呼ぶ）
     - 「Automatically expose new tables」：チェックなしでよい（関数を呼ぶ権限は SQL の中で渡している）
2. **表と関数を作る**
   - 左のメニューの「SQL Editor」を開きます。
   - このフォルダの `supabase_setup.sql` を全部コピーして、はりつけます。
   - 「Run」を押します。「Success」と出れば完了です。
3. **URL と鍵をゲームに書く**
   - 「Project Settings」→「API Keys」（または上の「Connect」）を開きます。
   - 次の2つを写して、`js_version/js/online_config.js` に書き入れます。
     - **Project URL**（`https://〜.supabase.co`）を `url` に入れる
     - **Publishable key**（`sb_publishable_〜`）を `key` に入れる
       - 古いプロジェクトでは anon public key（`eyJ〜`）でもよい
   - **secret key と service_role key は、絶対に書かないでください。** 公開してはいけない鍵です。
4. コミットして公開すると、オンラインのアカウントになります。

## 知っておくこと

- 設定を書く前に作ったアカウントは、この端末だけのアカウントです。オンラインにした後は、アカウントを作り直してください。
  - アカウントを作る前に遊んでいた時のバトルコインとマイベストは、その端末で最初に作るアカウントに引きつがれます。
- 通信が切れている間も遊べます。変えた所（名前・装備・クリアの記録）はその端末に残しておき、つながった時に送ります。メインメニューの右上が「オフライン」になります。
- PC とスマホで同時に保存しても、両方の変更が残ります（保存の番号 `version` で、あとから書く方が読み直してから保存します）。
- 無料のプロジェクトは、1週間くらい誰も使わないと止まります（pause）。止まったら、Supabase の画面で「Restore」を押すと戻ります。
- パスワードを8回続けてまちがえると、そのアカウントには5分間ログインできなくなります。
- パスワードを忘れた時に、メールで直すしくみはありません。メールアドレスを集めないためです。
  - 直す時は、SQL Editor で次を実行します。`ユーザー名` と `新しいパスワード` は書きかえてください。

```sql
update public.hk_accounts
set pass_hash = extensions.crypt('新しいパスワード', extensions.gen_salt('bf', 10)), failed_count = 0, locked_until = null
where username_key = lower('ユーザー名');
```
