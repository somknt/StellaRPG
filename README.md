# 星の子 (Hoshi no Ko)

## プロジェクト概要

2Dオープンワールド・ファンタジーRPG

### 使用技術
- **ゲームエンジン**: Godot 4.3
- **スクリプト言語**: GDScript
- **グラフィック**: 2Dピクセルアート（ドット絵）
- **視点**: トップダウン（見下ろし型）

### ワールドマップ - 12地域

1. **ティウム** - 主人公が育った小さな村（中央）
2. **ルナエビーナ** - 二つの月の光が差し込む神秘的な森（北西）
3. **ステラアンティ** - 星の民が残した古代遺跡（北中央）
4. **アルゲンツ** - 雪と氷に覆われた地域（北東）
5. **レギーア** - 魔法技術が発展した巨大な王都（東）
6. **星晶鉱山** - 星晶石が採掘される鉱山都市（中央東）
7. **ウィズデゼール** - 古代文明の遺跡が眠る砂漠（南東）
8. **エクリニグプ** - 黒紫色に侵食された危険地帯（東南端）
9. **ステラロクス** - 星の民の宇宙船が眠る墜落地（南東離れた地域）
10. **ルナムレモ** - 星の民の遺跡が残る静かな離島（南）
11. **ウラマリー** - 船が行き交う港町（南西）
12. **ウェントラン** - 草原と街道が広がる穏やかな地域（西）
