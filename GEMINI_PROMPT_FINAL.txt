2DファンタジーアクションRPG「星の子 (Hoshi no Ko)」のキャラクタースプライトを作成してください。

## ゲーム概要
- ジャンル: 見下ろし型2DアクションRPG
- 視点: トップダウン（上から見下ろす視点）
- スタイル: ドット絵（ピクセルアート）
- エンジン: Godot 4.3

## 世界観
主人公は人間と「星の民」のハーフです。
星の民の特徴として、瞳がオレンジに近い黄色に輝きます。
美しい星空と自然に満ちたファンタジー世界を冒険します。

## アートスタイル
- 2Dドット絵（ピクセルアート）
- 32x48ピクセル（プレイヤー）
- ファンタジーRPGの雰囲気
- 柔らかく温かみのある色彩

## 技術仕様
- ファイル形式: PNG（透過背景）
- サイズ: 正確に32x48ピクセル
- アニメーション: 横並びスプライトシート

# 主人公の歩行アニメーションスプライト作成

## キャラクター設定
- 年齢: 16〜18歳
- 性別: 中性的な外見
- 髪色: **黒に近い茶色（ダークブラウン）**
- 瞳の色: **オレンジに近い黄色**（星の民の特徴として輝く）
- 服装: **茶色っぽい旅人の服装**（シンプルな冒険者スタイル）
- 武器: 小さな剣を腰に装備
- 全体の雰囲気: 純粋で優しい、冒険者

## 正確なカラーパレット
- **髪**: #3d2817（ダークブラウン、黒に近い茶色）
- **瞳**: #ffb347（オレンジがかった黄色、星の民の特徴）
- **服**: #8b6f47（茶色の服）
- **肌**: #ffcdb2（明るい肌色）
- **剣**: #c0c0c0（銀色）

## 必要なスプライト

### 歩行アニメーション（下向き・正面）
- 方向: 下向き（プレイヤーの背中が見える正面向き）
- コマ数: 3コマ
- サイズ: **正確に32x48ピクセル**
- アニメーション: 歩く動作（左足→両足→右足）

## 重要な指示

1. **サイズ厳守**: 1コマは正確に32ピクセル（横）× 48ピクセル（縦）
2. **スプライトシート形式**: 3コマを横一列に等間隔で並べて1枚の画像にする
   - 最終画像サイズ: 96ピクセル（横）× 48ピクセル（縦）
3. **透過背景**: 背景は完全に透明にする
4. **ドット絵スタイル**: ピクセルアートで作成
5. **色の正確性**: 上記のカラーパレットを正確に使用

## 出力イメージ
```
[コマ1: 32x48px][コマ2: 32x48px][コマ3: 32x48px]
└────────── 合計96x48pxの1枚のPNG ──────────┘
```

使い方
====================================================================

1. Geminiを開く: https://gemini.google.com/

2. 【1】をコピーして送信 → Geminiの理解を確認

3. 【2】をコピーして送信 → 画像生成を待つ（数分）

4. 完成したら【3】のチェックリストで確認

5. 問題があれば【4】の修正依頼を送る

6. 完成したらダウンロード → assets/characters/ に保存

7. Godotに読み込んでテスト

====================================================================
Godotでの使い方
====================================================================

1. Godotエディタで「星の子」プロジェクトを開く

2. FileSystemパネルで assets/characters/ を開く

3. player_walk_down.png をドラッグ＆ドロップ

4. ファイルをクリック → Import タブ
   - Filter: Nearest に変更
   - Reimport をクリック

5. scenes/player/player.tscn を開く

6. AnimatedSprite2D ノードを選択
   - Texture に player_walk_down.png を設定
   - HFrames を 3 に設定
   - Animation を "walk" に設定

7. F5キーでゲーム実行 → プレイヤーが歩く！
