WASD / 矢印

左クリック / Space

敵をクリック
その敵をターゲット（ロックオン）にする。いつもその敵の方を向き、攻撃も魔法もその敵へ
F / ホイール押し
ターゲットの解除（ターゲットがいない時は、カーソルの下か近くの敵をターゲットに）
右クリック / C
回避（スタミナを使う）
Q
魔法陣（詠唱 → 発動）。1回押しはターゲット・近くの敵を自動でねらう。長押しするとマウスカーソルの方へ
