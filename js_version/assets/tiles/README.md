## 📐 画像仕様

### サイズ
- **基本タイル**: 128×128ピクセル
- **民家**: 384×384ピクセル（3×3タイル）
- **雑貨屋**: 512×384ピクセル（4×3タイル）
- **村長の家**: 512×512ピクセル（4×4タイル）

### フォーマット
- PNG形式（透過対応）
- 背景透明（建物・装飾タイル）
- シームレス対応（地面タイル）

### スタイル
- トップダウン視点（真上から見下ろし）
- 高品質なアニメ調
- 明るく温かみのある配色

## 🚀 使用方法

1. ChatGPTでタイル画像を生成
2. このフォルダに配置
3. ゲームを起動すると自動的に読み込まれます

## 📝 画像生成プロンプト

プロジェクトルートの `ChatGPT_ティウム村画像生成.txt` を参照してください。

## ⚙️ 技術詳細

- 画像は `assets.js` で管理
- `map.js` で自動的に描画
- 画像がない場合は色でフォールバック表示
- 128pxの高解像度画像を32pxのタイルサイズに自動スケーリング
