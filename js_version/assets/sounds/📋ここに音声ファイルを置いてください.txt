音声ファイルの置き場所（ファイルを置くだけで鳴ります）
====================================================================

  効果音        → このフォルダの中の  se/   に置く
  BGM・ジングル → このフォルダの中の  bgm/  に置く

  ・ファイルの名前は、下の一覧の名前と「まったく同じ」にする（半角の小文字・_ も同じ）
      例：se/attack.mp3   bgm/bgm_title.mp3
  ・形式は mp3（おすすめ） / ogg / wav のどれでもよい
  ・置いていない音は鳴らないだけ。1つずつ足していけばよい
  ・「代わり」と書いてある音は、その音がない時に代わりの音が鳴る
      例：bgm_boss だけ置けば、3体のボス戦すべてでその曲が流れる
  ・魔道ゴーレムの golem_boot・golem_roar・golem_thud は、ファイルがない間は
    プログラムで作った機械の音が鳴る（置けばそのファイルに変わる）

  ・効果音は、名前の後ろに _2 _3 _4 を付けたファイルも置ける。鳴らすたびにどれかがランダムに鳴る
      例：attack.mp3 と attack_2.mp3 → ナイフを振るたびに、どちらかの音
  ・ファイルの最初の無音は自動で飛ばすので、そのまま置いてよい
  ・音の大きさ・高さ・長さは js/sound.js の SoundManager.LIST（volume・rate・dur）で調整できる

  ・置いたあとは、ブラウザでページを読み直す（Ctrl+F5）
  ・どれが読みこめたかは、ブラウザのコンソール（F12）で
      soundManager.status()
    と打つと一覧が出る
  ・ブラウザ・スマホは、最初に画面をさわるまで音を出せないので、
    タイトル画面のBGMは「最初にさわった時」から流れる

  ファイルがない音のうち、近い音を高さを変えて代わりに鳴らしている物
    ファイヤーボール・ウォーターボールが当たった時（撃つ音を低く）／ストーンキャノン（回避の音を低く）
    イノシシの牙・狼の爪と噛みつき・ゴーレムの拳（ナイフの音の高さを変えて）
    狼の影の高速移動（回避の音を低く）／魔法の切りかえ（カーソル移動の音を高く）／選べない（戻るの音を低く）
    → その名前のファイルを置けば、そちらに変わる

--------------------------------------------------------------------
音の目安
--------------------------------------------------------------------
  効果音：0.2〜1.5秒くらい。最初に無音がない物（押した瞬間に鳴るように）
  BGM　 ：1〜3分。最後と最初が自然につながる（ループ）曲
  大きさ：効果音は 1つ 200KB くらいまで、BGM は 1曲 3〜5MB くらいまでがおすすめ
          （大きいとスマホで読みこみが遅くなる）

  入手先の例（それぞれの利用規約を確認してください）
    魔王魂　　　　　https://maou.audio/
    効果音ラボ　　　https://soundeffect-lab.info/
    DOVA-SYNDROME　https://dova-s.jp/

  名前を足したい・変えたい時は js/sound.js の SoundManager.LIST を書きかえる
