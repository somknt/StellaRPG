# ティウム村（始まりの村）画像生成プロンプト

## 【全体コンセプト】
温かく平和な農村。主人公の故郷で、物語の始まりの地。
小さいが活気があり、人々が助け合って暮らしている。

## 【村の配置・構造】
- 中央に小さな広場と井戸
- 広場の周りに民家5～6軒
- 村の入口に看板「ティウム村へようこそ」
- 北側に小さな畑（麦、野菜）
- 南側に村長の家（少し大きめ）
- 東側に雑貨屋（アイテムショップ）
- 西側に森への道
- 村の外周に簡単な木の柵

## 【建物デザイン】
- 木造の民家、茅葺き屋根または赤い瓦屋根
- 素朴で温かみのある中世ヨーロッパ風
- 煙突から煙が出ている家もある
- 窓には木製の鎧戸
- ドアは木製で丸みを帯びたデザイン

## 【地形・環境】
- 草原の中の村
- 周囲を緩やかな丘に囲まれている
- 北東に小さな川が流れている
- 道は土と石の混じった自然な感じ
- 所々に木や花が植えられている

## 【雰囲気・色調】
- 明るく穏やかな昼間の光
- 緑豊かで爽やか
- 青空に白い雲
- 夜空には二つの月（ツインムーン）が見える

## 【重要ポイント】
- 上から見下ろす俯瞰視点（トップダウン/見下ろし型RPG用）
- 高解像度の美麗なアニメ調グラフィック
- タイル配置できるようなシンプルなデザイン
- 128×128ピクセルの高品質タイルで構成

## 【推奨解像度】
- **基本タイル**: 128×128ピクセル（地面、小物）
- **建物タイル**: 256×256、384×384、512×512ピクセル（サイズに応じて）
- **全体マップ**: 2560×1920ピクセル（高解像度版）

## 【シームレスタイル生成の重要ポイント】

### ❌ やってはいけないこと
- タイルの端に黒い線や境界線を描く
- タイルの四隅に格子状の線を入れる
- 端だけ暗くする
- グリッド状の模様を入れる

### ✅ 正しいシームレスタイルの作り方
- タイル全体が均一な質感
- 端の模様が反対側の端と自然に繋がる
- 上下左右どこに並べても違和感がない
- 境界線が一切見えない
- タイルを4つ並べた時に十字の線が見えない

```
【問題点】
タイルの端に黒い線（グリッド線）が入っています。

【修正内容】

【確認方法】
- タイルを2×2で4枚並べてみて、境界線が見えないことを確認
- 端から端まで均一な草原の質感

サイズ：128×128ピクセル
スタイル：高品質なアニメ調
重要：グリッド線、境界線、ボーダーは一切描かないでください
```

## 【完璧なシームレスタイルの例】

良い例：
```
┌────────┬────────┐
│ 草草草 │ 草草草 │  ← 境界線が見えない
│ 草花草 │ 草草花 │
│ 草草草 │ 草草草 │
├────────┼────────┤  ← ここに線が見えない
│ 草草草 │ 草花草 │
│ 草草花 │ 草草草 │
│ 草草草 │ 草草草 │
└────────┴────────┘
```

悪い例：
```
┏━━━━━━┳━━━━━━┓
┃ 草草草 ┃ 草草草 ┃  ← 黒い線が見える（NG）
┃ 草花草 ┃ 草草花 ┃
┃ 草草草 ┃ 草草草 ┃
┣━━━━━━╋━━━━━━┫  ← 十字の線が見える（NG）
┃ 草草草 ┃ 草花草 ┃
┃ 草草花 ┃ 草草草 ┃
┃ 草草草 ┃ 草草草 ┃
┗━━━━━━┻━━━━━━┛
```
