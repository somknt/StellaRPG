# データファイル説明

## enemies.csv / enemies.json

敵キャラクターの基本データ

### データ項目

| 項目 | 型 | 説明 |
|---|---|---|
| enemyId | string | 敵の一意識別ID（enemy_001形式） |
| name | string | 敵の名前 |
| category | string | 分類（野生/精霊/侵蝕/人間/白暁/機械/戦争遺物/異形） |
| region | string | 出現地域 |
| level | number | 推奨レベル |
| hp | number | HP（ヒットポイント） |
| attack | number | 攻撃力 |
| defense | number | 防御力 |
| exp | number | 撃破時の獲得経験値 |
| drop | string | ドロップアイテム |
| spawnWeight | number | 出現重み（高いほど出やすい） |

### 追加情報（JSONのみ）

| 項目 | 型 | 説明 |
|---|---|---|
| aiType | array | AIタイプ（複数可） |
| element | string | 属性（無/炎/水/風/雷/光/闇） |
| weakness | array | 弱点属性 |
| corruptionLevel | number | 星喰い侵蝕度（1〜3、該当する場合のみ） |
| description | string | 敵の説明文 |

---

## 使用方法

### CSV形式
- スプレッドシートで編集可能
- データベースへのインポートに適している
- バランス調整時の一括編集に便利

### JSON形式
- ゲームエンジンでの読み込みに適している
- 追加情報を含む完全なデータ
- Godot、Unity、JavaScriptなどで直接利用可能

## データのバランス方針

### レベルと基本ステータス

基本的な計算式：
- **HP**: `25 + (level - 1) × 15`（基準値）
- **攻撃力**: `7 + (level - 1) × 3`（基準値）
- **防御力**: `level ÷ 5`（基準値）
- **経験値**: `5 + (level - 1) × 7`（基準値）

実際の値は敵の特性に応じて調整：
- **高耐久型**（ゴーレム、盾兵など）：HP +50%、防御力 +50%
- **速攻型**（弓兵、精霊など）：攻撃力 +30%、HP -20%
- **ボス**：全ステータス +100%以上

### 出現重み（spawnWeight）

- **40**: 非常によく出現（角ウサギ、洞窟コウモリなど）
- **30-35**: よく出現（草原狼、白暁歩兵など）
- **20-25**: 普通（精霊系、盗賊など）
- **15**: やや珍しい（侵蝕生物、虚無獣など）
- **10**: 珍しい（侵蝕核など）

## ドロップアイテム

### 野生生物
- 素材系：毛皮、牙、獣皮、翼など
- 用途：装備の強化、クラフト

### 精霊系
- 魔法素材：精核、結晶、鱗粉など
- 用途：魔法陣の強化、魔道具の作成

### 侵蝕生物
- 汚染素材：侵蝕した牙、黒晶石、影の残滓など
- 用途：特殊な装備、星喰い関連のアイテム

### 人間系
- 装備破片：短剣、弓弦、鋼の破片など
- 用途：装備の修理、強化

### 白暁騎士団
- 軍用品：徽章、矢束、盾片、星晶石など
- 用途：装備の強化、売却

### 機械系
- 機械部品：歯車、部品、星紋板など
- 用途：魔導機械の修理、魔道具の作成

### 戦争遺物
- 古代部品：記録片、魔導核、制御板など
- 用途：古代技術の研究、特殊装備

### 異形系
- 特殊素材：虚無の結晶、侵蝕核片など
- 用途：最強装備の作成、終盤のクラフト
